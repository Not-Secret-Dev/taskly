# taskly ✦

A colorful terminal todo manager written in Go. No dependencies, just a CSV file.

## Features
- Priorities (High / Normal / Low) with color-coded badges
- Due dates with overdue ⚠ and due-today ⏰ flags
- Progress bar and stats
- Toggle, add, and delete tasks
- Plain CSV storage, so you can open it in Excel

## Run
    go run main.go

## Build
    go build -o taskly
